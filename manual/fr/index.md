DrawNote
------
Bienvenue sur DrawNote ! DrawNote est une application multifonction qui réunit la prise de notes, l'écriture, les cartes mentales, les listes de tâches, l'écriture manuscrite et le dessin pour des utilisateurs de nombreux domaines. Ce manuel présente les fonctions et opérations courantes de DrawNote afin de vous aider à démarrer rapidement.
